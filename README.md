# VIP NETWORK TV — GitHub Pages

Upload these files to the root of a new GitHub repository:

- `index.html`
- `style.css`
- `script.js`
- `playlist.m3u`
- `searching-channel.mp4`
- `vip-network-logo.jpg`
- `README.md`

## Player behavior

- Categories: ALL / SPORTS / BD / INDIA / OTHERS
- Channel search
- Playlist `tvg-logo` is displayed as a circular channel logo
- Working stream URL → plays the stream
- Missing stream URL → automatically plays `searching-channel.mp4`
- Stream URL exists but fails or does not start within 12 seconds → automatically plays `searching-channel.mp4`
- Missing/down stream also shows Google and YouTube search buttons
- Messenger: https://m.me/alexranaroy
